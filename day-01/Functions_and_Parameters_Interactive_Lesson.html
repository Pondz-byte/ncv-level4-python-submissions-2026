🧰 Function Builders: Functions and Parameters

Learn how to create reusable blocks of Python code, pass information into functions using parameters and arguments, and return results to the main program.

Learning outcomes: define and call a function; use parameters and arguments; return a value; use functions to divide a problem into smaller tasks.

Part 1 · Hook

🏪 The tuck-shop calculator

A tuck shop sells an item. Each time the cashier needs the total price, the same calculation is performed. Instead of writing the calculation repeatedly, we can create a function and reuse it.

Without a function

price1 = 12
qty1 = 3
total1 = price1 * qty1
print(total1)

price2 = 8
qty2 = 4
total2 = price2 * qty2
print(total2)

The calculation is repeated in different places.

With a function

def calculate_total(price, quantity):
    total = price * quantity
    return total

print(calculate_total(12, 3))
print(calculate_total(8, 4))

Write the calculation once and call it whenever it is needed.

Think about it: Which version would be easier to update if the calculation changed?
Presenter prompt: Ask learners to identify the repeated instructions. Explain that a function is a named, reusable block of code.
Part 2 · Understand

🧠 What is a function?

A function is a named block of code designed to perform a particular task. It runs when it is called. Functions help make programs organised, reusable and easier to test.

Basic structure 
def function_name(parameters):
    # instructions
    return result
  • def tells Python that a function is being defined.
  • function_name is the name used to call the function.
  • parameters are variable names that receive information.
  • The indented lines form the function body.
  • return sends a result back to the place where the function was called.

1. Define a function

def greet():
    print("Welcome to Python")

This creates the function. It does not run yet.

2. Call a function

greet()

This tells Python to execute the function.

Try it: predict the output

def greet():
    print("Welcome!")

print("Start")
greet()
print("Finish")
Start
Welcome!
Finish
The function runs only when Python reaches greet().

📦 Parameters and arguments

A parameter is a variable listed inside the function definition. An argument is the actual value supplied when the function is called.

def greet_student(name):  # name is a parameter
    print("Hello", name)

greet_student("Lerato")  # "Lerato" is an argument
TermMeaningExample
ParameterVariable in the function definitionname
ArgumentValue passed into the function call"Lerato"
Remember: Parameters are placeholders. Arguments are the values that fill those placeholders.

↩️ Return versus print

print()

def add(a, b):
    print(a + b)

add(4, 6)

Displays the answer on the screen. It does not send the answer back for further calculation.

return

def add(a, b):
    return a + b

answer = add(4, 6)
print(answer)

Sends the answer back so the program can store it, display it or use it in another calculation.

Part 3 · Follow the values

🔍 Trace a function call

Study this program. Follow the arguments into the function, then follow the returned value back to the main program.

def calculate_area(length, width):
    area = length * width
    return area

room_area = calculate_area(5, 3)
print("Room area:", room_area, "square metres")
StepWhat happens?Value
1Python reaches the function callcalculate_area(5, 3)
2Arguments are assigned to parameterslength = 5, width = 3
3Function calculates the areaarea = 5 * 3 = 15
4Function returns the result15
5Main program stores and displays itroom_area = 15
Room area: 15 square metres
Ask learners: What would happen if the function call used calculate_area(8, 4)? Which values would change?
